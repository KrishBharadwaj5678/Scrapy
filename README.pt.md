## <img src="https://github.com/KrishBharadwaj5678/Scrapy/raw/main/assets/readme/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Scrapy.git
```

### 2️⃣ Acessar o Projeto

```bash
cd Scrapy
```

### 3️⃣ Instalar as Dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Configurar o MongoDB

Abra o arquivo spiders/main.py e defina a URI de conexão do MongoDB:

```bash
MONGO_URI = "mongodb_url"
```

Substitua "mongodb_url" pela sua string de conexão do MongoDB.

### 5️⃣ Iniciar o MongoDB

Certifique-se de que o MongoDB esteja em execução localmente ou que sua URI de conexão esteja acessível.

### 6️⃣ Acessar a Pasta

```bash
cd spiders
```

### 7️⃣ Executar o Spider

```bash
scrapy crawl main
```
