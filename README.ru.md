## <img src="https://github.com/KrishBharadwaj5678/Scrapy/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/Scrapy.git
```

### 2️⃣ Переход в проект

```bash
cd Scrapy
```

### 3️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4️⃣ Настройка MongoDB

Откройте spiders/main.py и укажите URI для подключения к MongoDB:

```bash
MONGO_URI = "mongodb_url"
```

Замените "mongodb_url" на вашу строку подключения MongoDB.

### 5️⃣ Запуск MongoDB

Убедитесь, что MongoDB запущена локально или что указанный URI подключения к MongoDB доступен.

### 6️⃣ Переход в папку

```bash
cd spiders
```

### 7️⃣ Запуск паука

```bash
scrapy crawl main
```
